NiRepurpose follows the **Suncoast Servers** pull-request workflow. Read the org guide first, then this repo’s onboarding doc.

| Resource | Purpose |

| [docs/COLLABORATOR.md](docs/COLLABORATOR.md) | Clone URL, branches, local checks |
| [AGENTS.md](AGENTS.md) | Rules for AI coding assistants |
| [docs/ROADMAP.md](docs/ROADMAP.md) | Priorities and release goals |
| [docs/TOOLCHAIN.md](docs/TOOLCHAIN.md) | Pinned ffmpeg/ExifTool, weekly update automation, maintainer setup |

**Merge authority:** [@TheDevWhoSaysNi](https://github.com/TheDevWhoSaysNi) — contractors open PRs; Ryan merges after review.

**Never push directly to `main`.** The `main` branch is protected (required PR + approval + CODEOWNERS review).
